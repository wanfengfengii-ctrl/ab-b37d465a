# 海岸遗址航拍覆盖认证

测绘员在浏览器中录入**逆时针凸多边形**发掘区工作区与 **3–12 条**矩形覆盖带
（整数中心、宽高、角度），对草稿发起认证，在平面图与明细中查看各带、覆盖结论
与风险区域。所有计算**仅在本地浏览器**完成，无后端、无网络请求、无第三方运行时依赖。

## 判定方法（连续平面判定，非栅格、非固定采样）

1. 以每条覆盖带的 4 条边所在**无限直线**，对工作区递归做凸多边形半平面二分切割，
   得到一组互不重叠的凸**单元**；
2. 每个满维单元用其面积重心判定覆盖带位图（重心不可能落在切割线上，归属无歧义）：
   - 位图为 0 → **漏拍区**（工作区中未被任何带覆盖的点）；
   - 位数 ≥ 3 → **三重曝光区**（被三条及以上带同时覆盖）；
3. **边界接触计入覆盖**：半平面裁剪为闭包；另解析扫描两类零面积情形：
   - 三条带边界在发掘区内**共线重叠段**（`triple-boundary`）；
   - 三条带在**单点**接触（含 T 字接头，`triple-point`）；
4. 每个面积型风险区域逐边给出**边界证据**：该边来自发掘区第几号顶点边，
   或第几号覆盖带的第几条边，并附边长与端点坐标。

单元面积之和恒等于工作区面积（报告中给出闭合误差，通常为 0），
证明划分是精确的连续平面判定，没有任何栅格化或采样损失。

认证通过当且仅当：工作区每一点至少被 1 条带覆盖，且任一点至多被 2 条带覆盖。

## 草稿与报告

- 修改草稿（增删顶点/覆盖带、改任一参数、切换预设）会**立即撤销旧报告**，
  页面显示撤销提示，平面图仅回显当前草稿，需重新点击「发起认证」。
- 存在漏拍或三重曝光时，结论横幅与明细标出**首个风险区域**的类型、面积、
  位置及边界证据（漏拍优先于三重曝光，同类按面积降序）。

## 本地开发（Node 22+，无需安装依赖）

```bash
npm test     # 几何核心单元测试（node --test）
npm run build  # 零依赖构建：内联 ESM 到 public/，并做语法校验
npm run smoke  # 业务冒烟：合格 / 漏拍 / 三重 / 边界接触 / 非法草稿场景
npm run verify # 上面三步 + 前端交互垫片冒烟，任一失败即以非零码退出
```

构建产物为纯静态文件（`public/`），也可用任意静态服务器打开。

## Docker

```bash
# 启动 web（宿主机端口由 WEB_PORT 决定，默认 8080）
WEB_PORT=9000 docker compose up --build web
# 健康检查
curl -fsS http://localhost:9000/healthz   # → ok
```

一次性验证服务（自行退出，退出码报告测试 / 构建 / 冒烟结果）：

```bash
docker compose up --build verify
docker compose ps -a   # verify 的 STATUS 为 Exited (0) 表示全部通过
```

## 目录结构

```
src/geometry.mjs   连续平面判定核心（半平面切割、位图分类、边界证据）
src/app.mjs        前端交互（草稿、即时撤销、SVG 平面图、明细与风险卡）
src/index.html     页面结构
src/styles.css     样式
scripts/build.mjs  零依赖静态构建
tests/             单元测试、业务冒烟、前端交互垫片冒烟
Dockerfile         verify / builder / web 多阶段
docker-compose.yml web（健康检查，WEB_PORT）+ 一次性 verify
```
